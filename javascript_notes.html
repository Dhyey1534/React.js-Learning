01

Introduction to JavaScript

📖 Definition

JavaScript is a lightweight, interpreted, single-threaded programming language used to make web pages interactive. It is one of the three core technologies of the web (HTML, CSS, JS) and can run in browsers and on servers (Node.js).

What Can JavaScript Do?

  • Manipulate HTML elements (DOM)
  • React to user events (clicks, keystrokes)
  • Fetch data from servers (AJAX / Fetch API)
  • Build full-stack apps with Node.js
  • Create games, mobile apps, and desktop apps

Key Characteristics

PropertyValue
TypingDynamic (types checked at runtime)
ParadigmMulti-paradigm (OOP, Functional, Procedural)
ExecutionInterpreted / JIT compiled
ThreadingSingle-threaded with event loop
Created1995 by Brendan Eich (in 10 days!)
StandardECMAScript (ES6+ is modern JS)

Your First JavaScript Program

// Inline in HTML
<script>
  console.log("Hello, World!");
</script>

// External file: script.js
console.log("JavaScript is running!");
Hello, World!
JavaScript is running!
// Using alert, confirm, and console together
console.log("Program started");
alert("Welcome to JavaScript!");
console.log("Alert was shown");
const name = "Alice";
const greet = (n) => `Hello, ${n}!`;
console.log(greet(name));
Hello, Alice!
🎯 Interview Points
  • JS is not Java — completely different languages.
  • JS is single-threaded but handles async via the event loop.
  • ECMAScript is the spec; JavaScript is the implementation.
  • Modern JS = ES6 (2015) and beyond.

Variables — var, let, const

📖 Definition

A variable is a named container that stores data. In JavaScript, variables are declared using var, let, or const.

Syntax

var   variableName = value;
let   variableName = value;
const VARIABLE_NAME = value;

⚠️ Common Mistakes
  • Using var inside loops can cause unexpected closures.
  • const prevents re-assignment, but objects/arrays can still be mutated.
  • Forgetting to declare variables creates implicit globals.
const person = { name: "Bob" };
person.name = "Alice";  // ✅ OK — object mutated
person = {};             // ❌ TypeError — re-assignment
🎯 Interview Points
  • What is the Temporal Dead Zone (TDZ)? — The period between entering scope and the declaration being initialized; accessing let/const in TDZ throws ReferenceError.
  • Why prefer const by default, let when needed, and avoid var?
  • var is hoisted and initialized to undefined; let/const are hoisted but NOT initialized.

Comments

📖 Definition

Comments are non-executable text in code used for documentation and readability. JavaScript supports single-line and multi-line comments.

// Single-line comment — everything after // is ignored

/* Multi-line comment
   Useful for longer explanations
   or temporarily disabling code */

let x = 5;  // inline comment

/**
 * JSDoc comment — used for documentation
 * @param {string} name - The user's name
 * @returns {string} A greeting message
 */
function greet(name) {
  return `Hello, ${name}!`;
}
✅ Best Practices
  • Comment why, not what (the code shows what; the comment explains why).
  • Keep comments updated — outdated comments are worse than none.
  • Use JSDoc for public APIs and functions.

Loops

📖 Definition

Loops execute a block of code repeatedly until a condition becomes false. JavaScript provides multiple loop types for different use cases.

Loop Comparison

LoopBest ForRuns At Least Once?
forKnown number of iterationsNo
whileUnknown iterations, condition firstNo
do-whileMust run at least onceYes
for...inObject keys / propertiesNo
for...ofIterables (arrays, strings, sets)No

for Loop

// Syntax: for (init; condition; update)
for (let i = 1; i <= 5; i++) {
  console.log(`Step ${i}`);
}

// Loop backwards
for (let i = 5; i >= 1; i--) {
  console.log(i);
}
Step 1 / Step 2 / Step 3 / Step 4 / Step 5
5 / 4 / 3 / 2 / 1

while Loop

let count = 1;
while (count <= 5) {
  console.log("Count: " + count);
  count++;
}

// do-while — runs body first, then checks
let n = 10;
do {
  console.log("n = " + n);
  n++;
} while (n < 5);  // runs once even though 10 > 5
Count: 1 … Count: 5
n = 10

for…in and for…of

const person = { name: "Alice", age: 30, city: "NYC" };

// for...in iterates over KEYS (object properties)
for (let key in person) {
  console.log(`${key}: ${person[key]}`);
}
// name: Alice | age: 30 | city: NYC

const fruits = ["Apple", "Banana", "Cherry"];

// for...of iterates over VALUES (iterables)
for (let fruit of fruits) {
  console.log(fruit);
}
// Apple | Banana | Cherry

// for...of on a string
for (let char of "Hello") {
  process.stdout.write(char + "-");
}
// H-e-l-l-o-
🎯 Interview Points
  • Never use for...in on arrays — it iterates inherited properties too. Use for...of or forEach.
  • for...of works on any iterable: arrays, strings, Maps, Sets, generators.
  • Infinite loop occurs if the loop condition never becomes false — be careful!
  • do-while guarantees at least one execution — useful for input validation.

Arrays & Array Methods

📖 Definition

An array is an ordered, mutable collection of values. Arrays in JavaScript are dynamic (can grow/shrink), zero-indexed, and can hold mixed types.

// Creating arrays
const nums = [1, 2, 3, 4, 5];
const mixed = [1, "hello", true, null, { key: "val" }];
const empty = new Array(3);  // [empty × 3]

// Accessing
console.log(nums[0]);           // 1 (first)
console.log(nums[nums.length-1]); // 5 (last)
console.log(nums.at(-1));        // 5 (modern way)

// Modifying
nums[0] = 10;
console.log(nums);  // [10, 2, 3, 4, 5]

Core Array Methods

let arr = [1, 2, 3];

arr.push(4);       // [1,2,3,4]  — add to end
arr.pop();         // [1,2,3]   — remove from end
arr.unshift(0);   // [0,1,2,3] — add to front
arr.shift();       // [1,2,3]   — remove from front

// splice(start, deleteCount, ...items)
arr.splice(1, 1, 99);  // [1,99,3] — replace index 1
arr.splice(1, 0, 50);  // [1,50,99,3] — insert at 1

console.log(arr);
[1, 50, 99, 3]
const nums = [1, 2, 3, 4, 5, 6];

// map — transform each element
const doubled = nums.map(n => n * 2);
console.log(doubled);   // [2,4,6,8,10,12]

// filter — keep elements that pass the test
const evens = nums.filter(n => n % 2 === 0);
console.log(evens);     // [2,4,6]

// reduce — accumulate to single value
const total = nums.reduce((sum, n) => sum + n, 0);
console.log(total);     // 21

// find — first match
const firstBig = nums.find(n => n > 3);
console.log(firstBig);  // 4

// every & some
console.log(nums.every(n => n > 0)); // true  (all positive)
console.log(nums.some(n => n > 5));  // true  (6 > 5)

// sort (always pass comparator for numbers!)
const sorted = [10, 2, 30, 4].sort((a, b) => a - b);
console.log(sorted);    // [2,4,10,30]

// flat & flatMap
const nested = [1, [2, [3, 4]]];

Spread, Destructuring & Array.from

// Spread operator
const a = [1, 2, 3];
const b = [4, 5, 6];
const c = [...a, ...b];       // [1,2,3,4,5,6]
const copy = [...a];          // shallow copy

// Array destructuring
const [first, second, ...rest] = [10, 20, 30, 40];
console.log(first);   // 10
console.log(second);  // 20
console.log(rest);    // [30, 40]

// Swap with destructuring
let x = 1, y = 2;
[x, y] = [y, x];
console.log(x, y);  // 2 1

// Array.from
const chars = Array.from("hello");
console.log(chars);  // ["h","e","l","l","o"]

const range = Array.from({length: 5}, (_, i) => i + 1);
console.log(range);  // [1,2,3,4,5]
⚠️ Common Mistake — sort() without comparator

[10, 2, 30].sort() → [10, 2, 30] (sorts as strings!). Always use .sort((a, b) => a - b) for numbers.

🎯 Interview Points
  • map vs forEach: map returns a new array; forEach returns undefined.
  • slice vs splice: slice is non-mutating; splice mutates the original.
  • Array.isArray() is the correct way to check if something is an array (typeof [] returns "object").
  • reduce is the most powerful array method — it can implement map and filter.
  • Spread creates a shallow copy — nested objects are still referenced.
